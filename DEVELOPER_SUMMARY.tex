\subsection{Purpose}

This is the developer summary for the complete \texttt{\detokenize{dirac}} repository. It is not an executive summary. It explains what the project implements, how its parts fit together, which artifacts are authoritative, how every phase is regenerated, what is independently checked, and where the scientific claims stop.

The repository combines five concerns that must remain distinct:

\begin{enumerate}
\item exact real algebra for \texttt{\detokenize{Cl(4,4)}}, half-spin representations, split
octonions, and split-real triality;

\item reproducible numerical applications built on a pinned safe-Rust port of
SUNDIALS 7.8.0 CVODE;

\item curved Levi-Civita and Weitzenboeck spin geometry in signature \texttt{\detokenize{(4,4)}};
\item a commuting classical 16-component Einstein-spinor dark-sector model; and
\item byte-level source audit, notebook execution, publication, and release
verification.

\end{enumerate}

The primary developer rule is that generated output is not accepted merely because it can be regenerated. Exact claims, numerical claims, document semantics, hashes, and cross-clone behavior are checked through independent paths.

\subsection{Generated Rust contract}

The generated source embeds the matrices and input SHA-256 values needed by the application; it is tracked so a clean clone builds without first running a generator. Developers must edit the generator or upstream fixture, never hand-edit \texttt{generate\allowbreak{}d.rs}.

The four application manifests depend only on local paths \texttt{vendor/s\allowbreak{}undials\_\allowbreak{}rs/crate\allowbreak{}s/sundia\allowbreak{}ls\_core} and \texttt{vendor/s\allowbreak{}undials\_\allowbreak{}rs/crate\allowbreak{}s/cvode\_\allowbreak{}rs}. \subsection{Logged execution and backup behavior}

\texttt{run\_logg\allowbreak{}ed.ps1} and \texttt{run\_logg\allowbreak{}ed.sh} wrap gate commands. A log records UTC start time, repository, exact command, combined output, UTC finish time, and exit code. Logs are local scratch under \texttt{\detokenize{logs/}} and are not canonical evidence unless a tracked report quotes and independently checks their results.

Before replacing tracked generated files, gates call \texttt{backup\_f\allowbreak{}iles.py}. It copies each file into a UTC-stamped \texttt{backups/\allowbreak{}edits} directory, computes source and backup SHA-256/size, and atomically writes a manifest requiring every copy to match. Backup payloads are ignored; their manifests may remain as local verification evidence.

\subsection{Phase 1: exact algebra and triality}

Phase 1 builds a real integral 16-by-16 representation of \texttt{\detokenize{Cl(4,4)}}, verifies its full and even algebra ranks, constructs rank-eight half-spin projectors, and establishes irreducibility and inequivalence after restriction to \texttt{Spin(4,4\allowbreak{})}. It then constructs split-octonion multiplication and para-product tensors and solves the split-real triality related-triple equations.

Canonical fixtures:

\begin{itemize}
\item \texttt{artifact\allowbreak{}s/exact/\allowbreak{}cl44-see\allowbreak{}d.json};
\item \texttt{artifact\allowbreak{}s/exact/\allowbreak{}split-oc\allowbreak{}tonion.j\allowbreak{}son};
\item \texttt{artifact\allowbreak{}s/exact/\allowbreak{}triality\allowbreak{}44.json}.
\end{itemize}

The full Clifford module is real, 16-dimensional, and irreducible for \texttt{\detokenize{Cl(4,4)}}. Under \texttt{Spin(4,4\allowbreak{})} it decomposes as the direct sum of two inequivalent real eight-dimensional half-spin modules. Code and documentation must not collapse those distinct statements.

\subsection{Phase 2: triality transport}

The \texttt{studies/\allowbreak{}triality\allowbreak{}\_transpo\allowbreak{}rt} crate integrates a 24-state system formed by three linked eight-dimensional triality sectors. Generated constants are hash-linked to the exact fixtures. The application uses the pinned CVODE engine without changing vendor code. Independent checks validate sample grids, source hashes, equation residuals, invariant drift, summaries, and byte-identical replay.

\subsection{Phase 3: homogeneous spinor cosmology}

The \texttt{studies/\allowbreak{}spinor\_c\allowbreak{}osmology} crate integrates an 18-state real homogeneous nonlinear-spinor system and compares it with analytic condensate, density, potential, and Friedmann relations. This phase establishes the numerical pattern later reused and independently rederived in the curved Einstein-spinor applications.

\subsection{Phase 4: notebooks and publications}

Phase 4 generates and executes standalone WolframScript, Mathematica, and Jupyter artifacts. It builds the primary dissertation and a parallel teaching edition from Markdown to deterministic standalone LaTeX and warning-free PDFs. Notebook gates validate structure, fixed cell inventories, execution results, canonical hashes, and replay. The publication gate requires independent PDF builds to match byte-for-byte.

\subsection{Phase 5: curved Levi-Civita Einstein-spinor model}

Phase 5 constructs an explicit curved signature \texttt{\detokenize{(4,4)}} metric, vielbein, Christoffel symbols, Levi-Civita spin connection, real rank-16 spinor bundle, and invariant split bilinear. Exact Python and Wolfram paths independently verify the geometry and homogeneous Dirac contraction.

The \texttt{studies/\allowbreak{}einstein\allowbreak{}\_spinor\_\allowbreak{}44} crate solves an 18-state coupled system with no separate scalar field and no cosmological constant. Its selected potential is

\[
V(S)=\frac1{20}S+\frac{19}{20}S^{1/5},
\qquad S=\psi^{\mathsf T}C\psi.
\]

The linear term is dust-like at homogeneous background level. The fractional term has equation of state \texttt{\detokenize{w=-4/5}} and supplies negative pressure. These are model-internal analogies, not observational identifications.

\subsection{Phase 6: Weitzenboeck spin geometry}

Phase 6 replaces the Levi-Civita spin connection with a flat inertial Weitzenboeck connection in a declared proper frame. The geometry is metric-compatible, curvature-free, and torsionful. Exact checks verify the contortion decomposition, torsion scalar, TEGR boundary identity, and homogeneous spinor-operator relation. A separate application-owned Rust crate reproduces the reduced background dynamics without depending on the Phase 5 application crate.

\subsection{Phase 7: \texttt{\{x0,...,\allowbreak{}x7\}} component refinement}

Phase 7 adopts only the coordinate names and ordering \texttt{\{x0,x1,x\allowbreak{}2,x3,x4,\allowbreak{}x5,x6,x7\allowbreak{}\}} from the external bridge reference. It does not import that reference's metric or connection. The refinement corrects the negative metric entries at indices 5, 6, and 7; separates covariant PDEs from the homogeneous system; expands the exact condensate and all 16 scalar spinor ODEs; and inventories all 8 diagonal and 28 independent off-diagonal homogeneous Einstein equations.

The tracked workspace \texttt{refineme\allowbreak{}nt/phase\allowbreak{}7-x0-x7} contains a claim ledger, exact/canonical evidence, convergence evidence, and a public-clone verification record. The final verified tag is \texttt{phase7-x\allowbreak{}0-x7-ref\allowbreak{}inement-\allowbreak{}green}.

\section{Exact mathematical core}

\subsection{Clifford representation}

The gamma generators are real integral 16-by-16 matrices satisfying

\[
\gamma^a\gamma^b+\gamma^b\gamma^a=2\eta^{ab}I_{16},
\qquad
\eta=\operatorname{diag}(1,1,1,1,-1,-1,-1,-1).
\]

Rank computations certify the full matrix algebra and even subalgebra. The chirality projector splits the module into two rank-eight summands. Commutant and intertwiner calculations establish irreducibility and inequivalence over the real numbers.

\subsection{Split octonions}

The split-octonion fixture records all 64 integral structure constants, conjugation, quadratic norm, ordinary multiplication, and para-product data. Exact tests establish the unit, norm composition, alternativity, and tensor nondegeneracy. The implementation does not assume associativity.

\subsection{Triality}

The related-triple linear system has dimension 28. Three pairwise inequivalent eight-dimensional modules preserve a nondegenerate trilinear form. A six-element outer action realizes the triality permutations, and an explicit invertible link connects the split-octonion model to the canonical Clifford representation.

\section{Curved spin geometry}

The homogeneous Phase 5/7 metric uses \texttt{\detokenize{x4}} as proper evolution coordinate:

\[
g_{\mu\nu}=\operatorname{diag}
(a^2,a^2,a^2,a^2,-1,-a^2,-a^2,-a^2).
\]

A constant-\texttt{\detokenize{x4}} slice has signature \texttt{\detokenize{(4,3)}}. The spin derivative convention is

\[
D_\mu=\partial_\mu+\frac18\omega_{\mu ab}[\gamma^a,\gamma^b],
\]

with both ordered tangent indices summed. For a homogeneous spinor, the Levi-Civita contraction is

\[
\gamma^\mu D_\mu\psi
=\gamma^4\left(\partial_{x4}+\frac72H\right)\psi.
\]

The covariant action, stress tensor, unrestricted field equations, homogeneous component expansion, and exact sign conventions are documented in the Phase 5 and Phase 7 provenance reports.

\section{Einstein-spinor numerical method}

The production solver uses the pinned safe-Rust SUNDIALS CVODE 7.8.0 port: variable-step, variable-order BDF (orders 1 through 5), default Newton iteration, an internal dense difference-quotient Jacobian, and an 18-by-18 dense direct linear solve. No comparative benchmark establishes this as a globally optimal integrator; it is the selected robust implementation.

At \texttt{\detokenize{x4=0}}, the canonical state has \texttt{\detokenize{a=1}}, \texttt{\detokenize{H=1}}, mathematical spinor components \texttt{\detokenize{psi_1=1}}, \texttt{psi\_16=1\allowbreak{}/2}, and all others zero. The application integrates independently backward to \texttt{\detokenize{-0.2}} and forward to \texttt{\detokenize{1.5}}, then joins the ordered samples.

Exact skew-adjointness gives

\[
\dot S=-7HS,
\qquad S=a^{-7}.
\]

This reduces the background to one quadrature and the rescaled spinor to eight rotations generated by \texttt{\detokenize{gamma^4}}. The canonical CVODE history is also checked by five-point finite differences for all 18 state equations and by a tighter convergence run.

\section{Verification strategy}

\subsection{Layered independence}

Verification is layered to avoid circular confidence:

\begin{enumerate}
\item fixture generators check internal invariants;
\item independent Python and Wolfram implementations reconstruct exact claims;
\item Rust unit tests exercise application-owned equations and domains;
\item Python output checkers recompute derived quantities from CSV state columns;
\item deterministic replay compares independent runs byte-for-byte;
\item refined runs test convergence under tighter tolerances and smaller steps;
\item semantic document checkers require formulas, scope statements, and claim
boundaries, not only hashes;

\item mutation tests prove that altered PDFs, torsion data, or reintroduced matrix
sums are rejected;

\item fresh recursive clones test line endings, submodule pins, paths, and public
availability.

\end{enumerate}

\subsection{Authority hierarchy}

When two files disagree, resolve ownership in this order:

\begin{enumerate}
\item declared mathematical conventions and project-owned generators;
\item canonical exact fixtures or numerical state artifacts;
\item independent executable checkers and machine-readable evidence;
\item current provenance Markdown;
\item deterministic LaTeX/PDF derivatives;
\item historical notebooks, reviews, or archived outputs.
\end{enumerate}

This hierarchy does not make generators infallible. A generator and its output can agree on the same bug; that is why independent derivations and mutation tests are required.

Those are future research questions, not implied results.

\section{Developer checklist}

Before editing:

\begin{enumerate}
\item identify the owning generator and independent checker;
\item confirm whether the target is source, canonical output, or derived
publication;

\item back up tracked generated files with \texttt{scripts/\allowbreak{}backup\_f\allowbreak{}iles.py};
\item keep external references and local prompts outside Git.
\end{enumerate}

Before pushing:

\begin{enumerate}
\item run focused tests immediately after the first change;
\item run the owning phase gate;
\item run the complete Python suite for shared checkers or publication code;
\item inspect \texttt{git diff\allowbreak{} --check} and tracked status;
\item push only intended files.
\end{enumerate}

After pushing:

\begin{enumerate}
\item compare local, tracking, and live remote refs;
\item clone recursively into a new directory;
\item rerun the owning gate and complete tests;
\item require strict root/submodule Git integrity and zero tracked drift;
\item record exact hashes, counts, commit, tag, and scientific boundaries.
\end{enumerate}
