# Real homogeneous nonlinear-spinor cosmology provenance

## Scope and limitations

This study reconstructs a homogeneous background with a 16-component real
field. It is not an observational fit, a perturbation analysis, or a claim of
microscopic uniqueness. The internal rotation is generated by an exact real
Clifford matrix; no non-real state or output is used.

The state is `(tau, rho, psi_0, ..., psi_15)` and the independent variable is
`N = ln(a)`. The equations are:

```text
dtau/dN = 1/E
drho/dN = -3 (1 + w(a)) rho
dpsi/dN = -(3/2) psi + (U_S/E) J psi

w(a) = w0 + wa (1-a)
E^2 = Omega_r0 exp(-4N) + Omega_m0 exp(-3N) + rho
```

`J` is a real skew 16-by-16 matrix satisfying `J^2 = -I`. The potential is
the independently checked reconstruction:

```text
U(S) = Omega_psi0 S^(1+w0+wa)
       exp[-3 wa (1 - S^(-1/3))]
S = psi^T psi
```

The two CVODE branches start at `N=0`, integrate to `N=-4` and `N=1`, and
join at the present epoch without duplication.
