\begin{Verbatim}[fontsize=\small]

\section{Exact initial-value problem solved}

State vector:

\[
y(x4)=(a,H,\psi_1,\ldots,\psi_{16})\in\mathbb R^{18}.
\]

The report uses one-based spinor labels. They map to zero-based code and CSV columns by \texttt{\detokenize{psi_A = psi(A-1)}}. Define

\[
U=\frac1{20}+\frac{19}{100}S^{-4/5}.
\]

The geometry equations are

\[
\dot a=aH,
\qquad
\dot H=-\frac{21}{6}(\rho+p).
\]

For each \texttt{\detokenize{j=1,...,8}}, the two spinor equations are exactly

\[
\dot\psi_j=-\frac72H\psi_j-U\psi_{j+8},
\qquad
\dot\psi_{j+8}=-\frac72H\psi_{j+8}+U\psi_j.
\]

This represents all 16 scalar equations; they are listed individually in the companion component report. The closures are

\[
S=\psi^{\mathsf T}C\psi,
\qquad
\rho=\frac{1}{20}S+\frac{19}{20}S^{1/5},
\]

\[
p=-\frac{19}{25}S^{1/5},
\qquad H^2=\rho.
\]

The reference state is imposed at \texttt{\detokenize{x4=0}}:

\[
a=1,
\quad H=1,
\quad \psi_1=1,
\quad \psi_{16}=\frac12,
\quad \psi_A=0\ \text{otherwise}.
\]

CVODE integrates independently from this state backward to \texttt{\detokenize{-0.2}} and forward to \texttt{\detokenize{1.5}}; the backward branch is reversed before both branches are joined.

\begin{enumerate}

\section{Exact reduction and approximate analytic solution}

Skew-adjointness of \texttt{\detokenize{gamma4}} with respect to \texttt{\detokenize{C}} gives

\[
\dot S=-7HS,
\qquad S(0)=1,
\qquad \boxed{S=a^{-7}}.
\]

The expanding background therefore reduces exactly to

\[
\rho(a)=\frac1{20}a^{-7}+\frac{19}{20}a^{-7/5},
\qquad H(a)=+\sqrt{\rho(a)},
\]

and one scalar quadrature:

\[
x4-x4_0=\int_{a_0}^{a}
\frac{d\tilde a}{\tilde a\sqrt{
(1/20)\tilde a^{-7}+(19/20)\tilde a^{-7/5}}}.
\]

For the spinor, define \texttt{\detokenize{chi=a^(7/2) psi}} and

\[
	heta(x4)=\int_0^{x4}U(S(s))\,ds.
\]

Then

\[
\dot\chi=-U\gamma^4\chi,
\qquad
\chi(x4)=\left(\cos\theta\,I_{16}
-\sin\theta\,\gamma^4\right)\chi(0).
\]

Thus every pair \texttt{\detokenize{j,j+8}} has the explicit reconstruction

\[
\begin{aligned}
\psi_j&=a^{-7/2}\left(
\cos\theta\,\psi_j(0)-\sin\theta\,\psi_{j+8}(0)\right),\\
\psi_{j+8}&=a^{-7/2}\left(
\sin\theta\,\psi_j(0)+\cos\theta\,\psi_{j+8}(0)\right).
\end{aligned}
\]

This reduces the approximate solution problem to quadrature for \texttt{\detokenize{a}} and \texttt{\detokenize{theta}}. It also supplies an independent structural check on all 16 numerical components.

Two useful single-term asymptotics are:

\begin{enumerate}
\item Linear-term dominance, with \texttt{\detokenize{m=1/20}}:
\end{enumerate}

\[
a(x4)^{7/2}\simeq a_r^{7/2}
+\frac72\sqrt{m}\,(x4-x4_r).
\]

\begin{enumerate}
\item Fractional-term dominance, with \texttt{\detokenize{lambda=19/20}}:
\end{enumerate}

\[
a(x4)^{7/10}\simeq a_r^{7/10}
+\frac7{10}\sqrt{\lambda}\,(x4-x4_r).
\]

The late expression corresponds to \texttt{\detokenize{a proportional to x4^(10/7)}} after an appropriate origin shift and is accelerating. These are regime-specific approximations; the canonical output integrates the full two-term system.

\section{Numerical approximation and error control}

The approximation strategy is fully controlled, not ad hoc:

\begin{enumerate}
\item Integrate the full coupled ODE once with canonical tolerances.
\item Repeat integration with identical settings to enforce byte-level replay.
\item Integrate a refined run with tighter controls (\texttt{\detokenize{rtol=1e-12}},
\texttt{\detokenize{atol=1e-14}}, \texttt{\detokenize{max_step=0.001}}).

\item Compare canonical and refined states componentwise.
\item Recompute every derived quantity from raw state output independently.
\end{enumerate}

Independent consistency checks applied to each equation family:

\begin{enumerate}
\item Friedmann closure check from the \texttt{\detokenize{44}} Einstein component.
\item Pressure/acceleration consistency from the spatial Einstein components.
\item Five-point finite-difference residual checks on all 18 ODE components.
\item Condensate power-law consistency:
\end{enumerate}

\[
S(x4)\sim a(x4)^{-7}.
\]

\begin{enumerate}
\item Deterministic replay byte-identity for history and summary artifacts.
\end{enumerate}

For nonzero expected value \texttt{\detokenize{q_ref}}, define

\[
\operatorname{rel}(q,q_{\rm ref})=
\frac{|q-q_{\rm ref}|}{\max(|q_{\rm ref}|,10^{-300})}.

The three invariant metrics are explicitly

\section{Equation-by-equation numerical treatment}

Each equation family is solved as part of the same implicit coupled system:

\begin{enumerate}
\item \texttt{\detokenize{a}} equation:
the nonlinear stage equation includes the product \texttt{\detokenize{a H}}; it is advanced in the same Newton solve as every other component.

\item \texttt{\detokenize{H}} equation:
nonlinear scalar equation coupled through \texttt{\detokenize{rho(S)}} and \texttt{\detokenize{p(S)}}.

\item Eight spinor pairs \texttt{\detokenize{(psi_j,psi_(j+8))}}:
each has the exact two-component rotation/dilution form in Section 1, while all pairs remain nonlinearly coupled through the shared condensate \texttt{\detokenize{S}}.

\end{enumerate}

No equation is decoupled or solved by shortcut substitution; all 18 components are advanced simultaneously in each implicit Newton solve. The canonical initial state leaves six spinor pairs identically zero, but their equations are still present and checked. Only the \texttt{\detokenize{(1,9)}} and \texttt{\detokenize{(8,16)}} pairs become nonzero.

\end{enumerate}

Interpretation guardrails:

\begin{enumerate}
\item These are model-internal effective-fluid analogies, not direct observational

\item Split signature \texttt{\detokenize{(4,4)}} is mathematically consistent in this framework but

Other spinor potentials, nonminimal curvature terms, torsion couplings, and inhomogeneous modes are mathematically possible but were not implemented. Accordingly, this is exhaustive only for the selected two-term potential and homogeneous ansatz.
